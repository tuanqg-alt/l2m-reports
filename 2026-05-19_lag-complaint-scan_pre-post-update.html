Methodology Notes

Data Source: NCSoft Logview — Purple Chat Log (clan chat) for L2M SA region. Log ID 3301 (GameChat), timezone ICT (UTC+7).

Keyword Filter: Raw keyword "lag" returns false positives from Indonesian/Filipino "lagi" (meaning "again/still"), "lagian", "lageh", etc. A word-boundary regex filter was applied to exclude these patterns. Filter pass rate increased from 10.2% → 26.0% post-update, indicating the post-update lag signal is more concentrated.

Window Clustering (±5 min): Messages within 5 minutes of each other are grouped into "lag event clusters." A cluster with ≥2 unique users indicates a shared/server-side lag event rather than individual connectivity issues.

VIP Mapping: 401 VIP players from Scope D config. Matched against char_name in chat logs. Tiers: G = >$20K LTV, F = $4K–20K, E = $2K–4K, D = $400–2K, C = $200–400, B = $40–200.

Caveat: Clan chat only — does not capture private/DM complaints, external social media, CS tickets, or players who quit silently.
